B.Tech Engineering Mini Project

MediCare – Smart Medicine Reminder System

An automated, browser-native assistive healthcare web application designed to solve patient medication non-adherence through proactive scheduling, real-time auditory chimes, and browser notifications.

Project Objective

According to the World Health Organization (WHO), over 50% of patients fail to take prescribed medications correctly. The goal of this mini project is to build an intuitive, zero-dependency, accessible reminder platform that runs natively in any standard web browser without demanding cloud logins or external backend servers.

Technology Stack

  • HTML5: Semantic layout, accessible input forms, dialog elements.
  • CSS3: Custom design system, CSS variables, flexbox, CSS grid, dark mode styling.
  • JavaScript (ES6+): Pure Vanilla JS with no external frameworks.
  • LocalStorage API: Client-side persistent key-value data storage.
  • Web Audio API: Synthesized loud, clear 3-beep medical alert chime without external audio files.
  • Notifications API: Native OS-level reminder notification popups.

Core Functionalities

  • Real-time background polling interval checking scheduled doses every 5 seconds.
  • Interactive reminder popup modal featuring 10-minute snooze and instant "Mark as Taken".
  • Comprehensive dashboard calculating real-time adherence rate and breakdown by dosage form.
  • Robust input validation preventing invalid or empty entries.
  • Full search, multi-criteria filtering, and column sorting capabilities.
  • 100% responsive design across smartphones, tablets, laptops, and 4K displays.

Client-side Storage Engine

MediCare operates entirely offline using browser LocalStorage. Medication profiles are serialized into structured JSON objects and safely queried upon page initialization. All user edits, deletions, snooze cycles, and adherence marks persist indefinitely across page reloads and browser sessions.

Faculty Demonstration Guide

To demonstrate this project to your professor or examiner:

  1. Click "Load Sample Data" from the Home view to instantly populate realistic morning, afternoon, and evening medications.
  2. Go to "Add Medicine", enter a test dose scheduled 1 minute ahead of the current live clock time, and click "Save Medicine".
  3. Wait for the clock to reach that minute. Observe the interactive reminder modal, hear the synthesized audio chime, and see the desktop notification trigger!
  4. Test clicking "Snooze 10 Mins" or "Mark as Taken".
  5. Visit the Dashboard to inspect how the Compliance Percentage and stat counters update automatically.
